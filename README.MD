# Student Activity Management Portal
A semantic, accessible webpage for viewing university events and registering for student activities.
## Technologies
- HTML5
- CSS3
- Git
## Features
- Semantic HTML structure
- Accessible event registration form
- Keyboard-friendly navigation
- Browser metadata
- Accessibility audit documentation
## How to run
Open `labexpt1.html` in a web browser.
## Accessibility testing
Run Lighthouse from Chrome Developer Tools or use the WAVE extension.
